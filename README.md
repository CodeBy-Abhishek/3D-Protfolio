# 3D Portfolio  (Next.js Edition)

## 🚀 Overview

This is a production-grade **Next.js 14** application demonstrating Full Stack capabilities.
It features:
- **3D Hero**: Interactive Robot using `@splinetool/react-spline`.
- **System Design**: Cyber-themed UI with TailwindCSS & Framer Motion.
- **Backend API**: Contact form simulation via Next.js API Routes.
- **Polyglot Script**: `health.py` for DevOps/Microservices demo.

## 🛠 Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000).

## 🤖 3D Model Configuration
To use your specific Chatbot model:
1. Open `components/Hero3D.tsx`.
2. Replace the `scene` prop URL with your Spline Export Code/Viewer URL.
